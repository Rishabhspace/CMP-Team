# 👨‍💻 Conference Management Portal - IIT Roorkee

Welcome to the official repository of the **Conference Management Portal (CMP)** of **IIT Roorkee** — a comprehensive platform designed to simplify the organization and management of academic conferences within the institute.

Built with a shared vision of enabling seamless registration, abstract submission, review workflows, and participant coordination, CMP aims to empower faculties and organizers with efficient digital tools.

---

## 🚀 Project Overview

The **Conference Management Portal** is a centralized web application tailored for the needs of IIT Roorkee. It supports:

- 📥 Paper/Abstract Submission
- 📝 Review & Approval System
- 💳 Payment Integration (if applicable)
- 📄 Certificate Generation
- 📧 Automated Email Notifications
- 🧾 Attendance & Scheduling Management
- 💬 Chat & Support Feature for Attendees
> From organizing paper tracks to sending notifications — CMP simplifies it all.

## 🛠️ Tech Stack

- **Frontend**: EJS / HTML / CSS / JS
- **Backend**: Node.js / Express.js
- **Database**: MongoDB 
- **Hosting**: AWS / GCP / Digital Ocean / Render / Vercel / Institute Server
- **Other Tools**: Git, GitHub, Figma (for UI/UX), Postman (for API Testing)
